## 0.2.0

### Minor Changes

- 8be55f8: New package. `kvStorage(db)` is persistence storage for the fate data client (`@nkzw/fate`) on an `@opfs-lsm/kv` db. It takes the place of the storage in `@nkzw/fate-indexeddb`. One fate entry is one kv entry, a `writeBatch` is one atomic kv batch, and each `exclusive` section holds a Web Lock and first catches the handle up with other tabs' writes.

### Patch Changes

- 83ce8e1: Every package now declares `sideEffects` in its `package.json`, so webpack and esbuild drop the modules an app does not import. With webpack, an app that imports only the error classes from `@opfs-lsm/kv` bundles 135 bytes brotli instead of 438, and no longer gets the SharedWorker chunk and the wasm file in its build output.
